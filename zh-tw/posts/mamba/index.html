什麼是序列模型？
#

序列模型（sequence model）可以看成一個把序列對應到另一個序列的函數，Transformer 就是最典型的例子。這類模型可以處理很多不同類型的問題與資料，包含文字、影像、聲音與影片。例如：

  • 語言模型：GPT、Claude、Gemini 等
  • 視覺語言模型：LLaVA，以及我在另一篇文章介紹過的 LLaVA-Med
  • 影像模型：各種 vision transformer

這些 state-of-the-art 的模型大多是以 Transformer 為基礎，也就是說，我們可以只用一種模型架構處理不同模態的問題。以 LLaVA 為例，影像會先經過 vision encoder 編碼成特徵向量，文字則經過 tokenizer 變成 token，接下來只要一個 Transformer-based 模型，就能完成分類，或是當作聊天機器人使用。ViT 做的事情也類似。

Transformer 為什麼這麼好用？
#

一個 Transformer block 包含 multi-head attention、layer norm、feed forward（MLP）、dropout 與 skip connection，其中最重要的是 multi-head attention。

有了 Transformer block 之後，要擴大模型非常容易：可以直接疊更多 block，或是使用 Mixture of Experts（MoE，例如 Mixtral 8×7B）。可以依需求輕鬆調整模型大小，這種簡單正是 Transformer-based 模型會流行的原因之一。

Scaling laws
#

Transformer 還有一個很重要的經驗法則：scaling laws。它是一種經驗觀察，目的是在訓練前，就依照資料量、總計算量與模型大小來預測模型的表現。

DeepMind 提出的 Chinchilla scaling law 是其中很有名的一個，其中 LLL 可以看成 loss，NNN 是模型參數量，DDD 是訓練用的 token 數：

L(N,D)=E+AN0.34+BD0.28,E=1.69, A=406.4, B=410.7L(N, D) = E + \frac{A}{N^{0.34}} + \frac{B}{D^{0.28}}, \quad E = 1.69,\ A = 406.4,\ B = 410.7L(N,D)=E+N0.34A​+D0.28B​,E=1.69, A=406.4, B=410.7

它的主要結論是：在固定的計算預算下，模型大小與訓練 token 數應該等比例放大，大約每個參數搭配 20 個訓練 token。換句話說，只要同時增加模型大小與資料量，就可以預期 loss 會降低。下圖是 OpenAI 更早的 scaling laws 研究，可以看到增加計算量、資料量與參數量時，test loss 都穩定下降。

Transformer 的限制
#

Transformer 在各種應用中都展現了強大的能力，也能透過增加資源輕易地提升表現。但它有一個問題：因為 attention 機制，計算量會隨著 context 長度呈平方成長。所以輸入與輸出的 token 數都有上限，不容易直接用在像影片這樣的長序列資料。

面對長序列資料，主流的解法有兩種：

  1. Retrieval-Augmented Generation（RAG）：像是一個擴充，從外部資料庫取回資料，再給出客製化的回答。就像考試可以帶小抄：考試前要先把資訊整理、濃縮在小抄上，考試時才能快速找到需要的內容。
  2. 加大 context window：直接讓模型一次能讀進更多 token，例如長達百萬 token 的 context window。

但不論哪一種，最好都能降低計算量，才能在長序列上更快地得到回覆。Mamba 正是為了在訓練與推論時有效率地處理長序列而設計的。

State Space Model
#

在介紹 Mamba 之前，需要先認識它的前身。我們從 state space model（SSM）開始，它來自控制理論，用微分方程描述一個動態系統：

x′(t)=Ax(t)+Bu(t)y(t)=Cx(t)+Du(t)\begin{aligned} x'(t) &= Ax(t) + Bu(t) \\ y(t) &= Cx(t) + Du(t) \end{aligned}x′(t)y(t)​=Ax(t)+Bu(t)=Cx(t)+Du(t)​

其中 u(t)u(t)u(t) 是輸入訊號，x(t)x(t)x(t) 是 state，y(t)y(t)y(t) 是輸出。AAA 是 state matrix，和 state 相乘；BBB、CCC 分別是 input matrix 與 output matrix；DDD 的作用類似 skip connection，通常直接設成 0 省略這一項。

SSM 的想法是：用一個比較小的 state 記住過去的資訊，有點像 RNN。這也是它處理長序列的方式。

離散化：recurrent 與 convolution 兩種觀點
#

SSM 中最重要的一步是離散化（discretization），因為它直接決定了訓練與推論的效率。離散化之後，連續系統可以轉換成兩種觀點。

第一種是 recurrent view。用梯形法（bilinear method）離散化，並取步長 Δ\DeltaΔ，系統可以改寫成遞迴式：

xk=Aˉxk−1+Bˉuk,Aˉ=(I−Δ2A)−1(I+Δ2A)yk=Cˉxk,Bˉ=(I−Δ2A)−1ΔB,Cˉ=C\begin{aligned} x_k &= \bar{A}x_{k-1} + \bar{B}u_k, & \bar{A} &= (I - \tfrac{\Delta}{2}A)^{-1}(I + \tfrac{\Delta}{2}A) \\ y_k &= \bar{C}x_k, & \bar{B} &= (I - \tfrac{\Delta}{2}A)^{-1}\Delta B, \quad \bar{C} = C \end{aligned}xk​yk​​=Aˉxk−1​+Bˉuk​,=Cˉxk​,​AˉBˉ​=(I−2Δ​A)−1(I+2Δ​A)=(I−2Δ​A)−1ΔB,Cˉ=C​

推論時就可以用這個式子產生輸出：下一個輸出只取決於目前的 state 與目前的輸入，所以推論非常有效率，就像 RNN 一樣。

第二種是 convolution view。把遞迴式展開，輸出可以寫成輸入和一個 kernel 的摺積：

y=Kˉ∗u,Kˉ=(CˉBˉ, CˉAˉBˉ, …, CˉAˉL−1Bˉ)y = \bar{K} \ast u, \qquad \bar{K} = (\bar{C}\bar{B},\ \bar{C}\bar{A}\bar{B},\ \dots,\ \bar{C}\bar{A}^{L-1}\bar{B})y=Kˉ∗u,Kˉ=(CˉBˉ, CˉAˉBˉ, …, CˉAˉL−1Bˉ)

訓練時整段序列都已經知道，就可以用摺積平行計算。這是 SSM 和 RNN 不同的地方：RNN 訓練時只能一步一步算。

矩陣 A 與 HiPPO
#

在 SSM 的設定中，BBB、CCC 是可學習的參數，而 AAA 的選擇很關鍵。摺積的 kernel 裡需要先算出 Aˉk\bar{A}^kAˉk，這仍然很耗時，所以 AAA 最好是 normal matrix，因為 normal matrix 可以被么正對角化（unitarily diagonalizable），次方就容易計算。

此外，SSM 用 HiPPO（High-Order Polynomial Projection Operator）矩陣來初始化 AAA。HiPPO 矩陣是從特定的 measure 推導出來的，能幫助 state 記住先前的資訊，相關的證明與實驗可以在同一位作者的論文中找到。S4 使用的版本（HiPPO-LegS）是：

Ank=−{2n+1 2k+1n>kn+1n=k0n<kA_{nk} = -\begin{cases} \sqrt{2n+1}\,\sqrt{2k+1} & n > k \\ n + 1 & n = k \\ 0 & n < k \end{cases}Ank​=−⎩⎨⎧​2n+1​2k+1​n+10​n>kn=kn<k​

不過這個矩陣不是 normal matrix。作者先把它分解成一個 normal matrix 加上一個低秩矩陣，再搭配他們的演算法，加速 recurrent 與 convolution 的計算。在實驗上，用 HiPPO 初始化的 SSM 表現很好，但隨機初始化 AAA 時則不然。

Structured State Space Model（S4）
#

把上面這些組合起來就是 S4：

S4 = SSM + HiPPO + Structured matrices

也就是使用 state space model、把 AAA 換成 HiPPO 矩陣，再用結構化矩陣與特別的演算法來學習參數。

S4 有幾個好用的性質：

  • Resolution invariant：因為模型來自連續系統，可以在低解析度的資料上訓練，再用在高解析度的資料上。這對聲音資料特別有用，可以降低取樣率來加速訓練。
  • 訓練有效率：訓練時可以用摺積平行計算。
  • 推論有效率：推論時可以用遞迴的方式計算。

Mamba
#

Albert Gu 與 Tri Dao 提出的 Mamba: Linear-Time Sequence Modeling with Selective State Spaces（程式碼在 GitHub），想解決的就是 attention 帶來的問題。它在 SSM 的基礎上加了兩個改進：

  1. Selective mechanism：讓模型可以依照輸入內容，決定要專注或忽略哪些資訊。
  2. Hardware-aware algorithm：針對 GPU 的記憶體結構設計計算方式。

根據論文的結果，Mamba 的推論 throughput 比 Transformer 高 5 倍，在語言、聲音與基因體等不同模態上都有 state-of-the-art 的表現；它也是第一個能追上 Transformer 表現的 attention-free 模型，Mamba-3B 的表現優於同樣大小的 Transformer。

符號與離散化
#

Mamba 論文的符號和前面稍有不同：hhh 是 state，xxx 是輸入，yyy 是輸出。連續系統與離散後的系統分別是：

h′(t)=Ah(t)+Bx(t)ht=Aˉht−1+Bˉxty(t)=Ch(t)yt=Cht\begin{aligned} h'(t) &= Ah(t) + Bx(t) & \qquad h_t &= \bar{A}h_{t-1} + \bar{B}x_t \\ y(t) &= Ch(t) & \qquad y_t &= Ch_t \end{aligned}h′(t)y(t)​=Ah(t)+Bx(t)=Ch(t)​ht​yt​​=Aˉht−1​+Bˉxt​=Cht​​

這裡改用 zero-order hold（ZOH）離散化：

Aˉ=exp⁡(ΔA),Bˉ=(ΔA)−1(exp⁡(ΔA)−I)⋅ΔB\bar{A} = \exp(\Delta A), \qquad \bar{B} = (\Delta A)^{-1}\left(\exp(\Delta A) - I\right) \cdot \Delta BAˉ=exp(ΔA),Bˉ=(ΔA)−1(exp(ΔA)−I)⋅ΔB

離散化和連續系統有深刻的關聯，讓模型具備 resolution invariance 等額外性質，也確保模型被適當地正規化。下圖是 Mamba 中 state space model 的架構，橘色部分是 state，AAA 負責從 state 中萃取特徵與資訊，BBB、CCC 則處理輸入與輸出。

第一個改進：Selective mechanism
#

S4 的 AAA、BBB、CCC、Δ\DeltaΔ 都和輸入無關，是 time-invariant 的。Mamba 讓 BBB、CCC、Δ\DeltaΔ 依照輸入而改變，也就是在演算法中多加了序列長度 LLL 這個維度，變成 time-varying：

其中：

sB(x)=LinearN(x)sC(x)=LinearN(x)sΔ(x)=BroadcastD(Linear1(x))τΔ=softplus\begin{aligned} s_B(x) &= \mathrm{Linear}_N(x) \\ s_C(x) &= \mathrm{Linear}_N(x) \\ s_\Delta(x) &= \mathrm{Broadcast}_D(\mathrm{Linear}_1(x)) \\ \tau_\Delta &= \mathrm{softplus} \end{aligned}sB​(x)sC​(x)sΔ​(x)τΔ​​=LinearN​(x)=LinearN​(x)=BroadcastD​(Linear1​(x))=softplus​

sBs_BsB​、sCs_CsC​、sΔs_\DeltasΔ​ 都是線性層，τΔ\tau_\DeltaτΔ​ 是 softplus（可以看成 ReLU 的平滑近似），而 selective mechanism 主要就在 sΔs_\DeltasΔ​ 與 τΔ\tau_\DeltaτΔ​。

Selective mechanism 和 RNN 中的 gate 有關。論文的 Theorem 1 看一個特例：當 N=1N = 1N=1、A=−1A = -1A=−1、B=1B = 1B=1、sΔ=Linear(x)s_\Delta = \mathrm{Linear}(x)sΔ​=Linear(x)、τΔ=softplus\tau_\Delta = \mathrm{softplus}τΔ​=softplus 時，selective SSM 的遞迴式會變成：

gt=σ(Linear(xt))ht=(1−gt) ht−1+gt xt\begin{aligned} g_t &= \sigma(\mathrm{Linear}(x_t)) \\ h_t &= (1 - g_t)\,h_{t-1} + g_t\,x_t \end{aligned}gt​ht​​=σ(Linear(xt​))=(1−gt​)ht−1​+gt​xt​​

這和 RNN 的 forget gate 非常相似：用 gate 決定要保留哪些資訊，是過去的 state，還是目前的輸入？證明可以在論文的附錄中找到。

第二個改進：Hardware-aware algorithm
#

加上 selective mechanism 之後，Aˉ\bar{A}Aˉ、Bˉ\bar{B}Bˉ 會隨著時間改變，就不能再用摺積的方式訓練。作者用三個經典的技巧來解決這個問題：

  • Kernel fusion
  • Parallel scan
  • Recomputation

其中最重要的是 parallel scan，它也被用在 linear RNN 的計算中。這些計算真正的瓶頸不是運算本身，而是 GPU 上兩種記憶體之間的 I/O：HBM（High Bandwidth Memory）與 SRAM（Static Random-Access Memory），其中 SRAM 比 HBM 快得多。所以主要的想法是：把離散化與 scan 這些關鍵步驟都放在 SRAM 中計算，以減少 I/O。

Mamba 的架構
#

H3 是 SSM 的一個分支。Mamba 把 H3 與 gated MLP 結合成一個 Mamba block，其中 gated MLP 通常被當作 self-attention 的替代品，參數量也比較少。Mamba block 可以像 Transformer block 一樣直接堆疊使用。

實驗結果
#

第一個實驗是在 The Pile 資料集上的 scaling laws，模型大小從 125M 到 1.3B。結果顯示 Mamba 和 Transformer 一樣遵循 scaling laws，而且在序列長度更長時也有類似的結果。

第二個實驗是效率。因為 hardware-aware algorithm，Mamba 的 scan 比 FlashAttention-2 與摺積都快，也讓 Mamba 有更高的推論 throughput，大約是 Transformer 的五倍。

結語
#

Mamba 從 state space model 出發，用 HiPPO 與 S4 打好記憶長序列與高效計算的基礎，再加上 selective mechanism 讓模型能依照內容選擇要記住什麼，最後用 hardware-aware algorithm 把效率補回來。

對我來說，這篇論文最有意思的地方在於它提供了 attention 以外的另一條路。值得持續關注 attention-free 的序列模型，嘗試把它們用在訓練與推論中，甚至用這類序列模型來建立 foundation model。
